# Number Rally

Math facts practice for kids: one-at-a-time practice, beat-the-clock drills, worksheets, and races against Robo. Built for tablets.

- Runs entirely in the browser. No accounts, no server, no tracking.
- Each kid's progress is saved only on the tablet it's played on. Grown-ups can save and restore backups from the "For grown-ups" screen (press and hold for 3 seconds).
- Add it to the home screen to open it full screen and use it offline.

## Hosting

Served by GitHub Pages from the `main` branch root. When you change any file, bump `VERSION` in `sw.js` so installed copies update.
